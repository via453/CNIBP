# TJC 串口屏设计指南

本文档用于指导在 USART HMI 软件中设计 TJC 串口屏界面，配合 STM32F103C8T6 + MAX30102 血氧检测项目使用。

---

## 1. 串口通信参数

| 参数 | 值 |
|------|------|
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 使用串口 | USART1 |

### 接线方式

```
STM32          TJC屏幕
PA9  (TX)  -->  RX
PA10 (RX)  <--  TX
GND        ---  GND
```

> 注意：STM32 的 TX 接屏幕的 RX，RX 接屏幕的 TX，交叉连接。

---

## 2. TJC 协议格式

### 2.1 命令终止符

所有命令必须以 **3 个 0xFF** 结尾，屏幕以此判断命令结束：

```
[命令内容]  0xFF  0xFF  0xFF
```

### 2.2 波形数据命令

向波形控件添加一个数据点：

```
add s{id}.id,0,{value}  0xFF 0xFF 0xFF
```

- `s{id}`: 波形控件名称，如 `s0`
- `0`: 通道号，固定为 0
- `{value}`: 数据值，范围 0-255

### 2.3 数值控件命令

设置数值控件的显示值：

```
{component}.val={value}  0xFF 0xFF 0xFF
```

- `{component}`: 控件名称，如 `n0`
- `{value}`: 要显示的数值

## 3. 需要设计的控件

在 USART HMI 软件中创建以下控件：

### 3.1 波形控件（Waveform）

| 属性 | 值 |
|------|------|
| 控件名称 | `s0` |
| 控件类型 | 波形（Waveform） |
| 数据范围 | 0 - 255 |
| 用途 | 显示 PPG 实时波形 |

**命令格式：**
```
add s0.id,0,{value}
```

**代码调用方式：**
```c
TJC_SetWaveform(0, normalized_value);  // channel=0, value=0~255
```

### 3.2 数值控件（Number）

| 属性 | 值 |
|------|------|
| 控件名称 | `n0` |
| 控件类型 | 数值（Number） |
| 数据范围 | 70 - 100（血氧百分比） |
| 用途 | 显示 SpO2 数值 |

**命令格式：**
```
n0.val={value}
```

**代码调用方式：**
```c
TJC_SetNumber("n0", spo2_value);  // 例如 spo2_value=98
```

### 3.3 文本标签（可选）

建议添加静态文本标签，方便识别：

| 标签内容 | 位置建议 |
|----------|----------|
| `SpO2:` | 数值控件 n0 左侧 |
| `%` | 数值控件 n0 右侧 |

## 4. 命令示例（十六进制）

### 4.1 波形命令示例

发送值 `128` 到波形控件 s0：

```
命令文本:  add s0.id,0,128
十六进制:  61 64 64 20 73 30 2E 69 64 2C 30 2C 31 32 38 FF FF FF
```

逐字节分解：
```
'a'  'd'  'd'  ' '  's'  '0'  '.'  'i'  'd'  ','  '0'  ','  '1'  '2'  '8'   结束符
61   64   64   20   73   30   2E   69   64   2C   30   2C   31   32   38   FF FF FF
```

### 4.2 数值命令示例

设置血氧值为 `98`：

```
命令文本:  n0.val=98
十六进制:  6E 30 2E 76 61 6C 3D 39 38 FF FF FF
```

逐字节分解：
```
'n'  '0'  '.'  'v'  'a'  'l'  '='  '9'  '8'   结束符
6E   30   2E   76   61   6C   3D   39   38   FF FF FF
```

## 5. USART HMI 界面设计建议

### 5.1 波形控件属性设置

| 属性 | 推荐值 | 说明 |
|------|--------|------|
| 宽度 | 400 | 占满屏幕宽度（480px屏幕） |
| 高度 | 200 | 适当高度显示波形细节 |
| 背景色 | 黑色 (0x0000) | 对比度高，便于观察 |
| 波形颜色 | 绿色 (0x07E0) | 类似医疗设备风格 |
| 通道数 | 1 | 只使用通道 0 |

### 5.2 数值控件属性设置

| 属性 | 推荐值 | 说明 |
|------|--------|------|
| 字体大小 | 48 或 64 | 大字体，远处可读 |
| 字体颜色 | 白色 (0xFFFF) | 清晰醒目 |
| 数字位数 | 3 | 最大显示 100 |
| 背景色 | 黑色 (0x0000) | 与波形区域统一 |

### 5.3 界面布局建议

```
+------------------------------------------+
|                                          |
|          [波形控件 s0]                    |
|          宽: 400  高: 200                |
|          黑色背景，绿色波形              |
|                                          |
+------------------------------------------+
|                                          |
|    SpO2:  [数值控件 n0]  %               |
|           字体 48pt，白色                |
|                                          |
+------------------------------------------+
```

**布局要点：**
- 波形控件放在屏幕上半部分，面积要大
- 数值控件放在屏幕下半部分，字体要大
- SpO2 标签和百分号用静态文本控件放在 n0 两侧
- 整体背景用黑色，营造专业仪器感

## 6. 调试方法

### 6.1 串口助手测试

使用串口调试助手（如 SSCOM、XCOM）手动发送命令，验证屏幕响应。

**测试波形控件：**
1. 打开串口助手，设置 115200 / 8N1
2. 勾选"发送 HEX"
3. 输入：`61 64 64 20 73 30 2E 69 64 2C 30 2C 31 32 38 FF FF FF`
4. 观察屏幕波形控件是否出现一个数据点

**测试数值控件：**
1. 输入：`6E 30 2E 76 61 6C 3D 39 38 FF FF FF`
2. 观察屏幕数值控件是否显示 98

**测试文本模式（更直观）：**
1. 取消勾选"发送 HEX"，切换到文本模式
2. 输入：`add s0.id,0,128`，然后手动追加三个 0xFF（勾选HEX发送 `FF FF FF`）
3. 或者使用支持混合发送的串口助手

### 6.2 常见问题和解决方案

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 屏幕无反应 | 接线错误 | 检查 TX/RX 是否交叉连接 |
| 屏幕无反应 | 波特率不匹配 | 确认屏幕工程设置为 115200 |
| 波形不显示 | 控件名称错误 | 确认波形控件名称为 `s0`（小写） |
| 数值不更新 | 控件名称错误 | 确认数值控件名称为 `n0`（小写） |
| 显示乱码 | 波特率不一致 | 检查 STM32 和屏幕波特率是否都是 115200 |
| 波形只有直线 | 数据恒定不变 | 检查 PPG 归一化是否正常工作（min==max 时返回 128） |
| 数值为 0 | 传感器未连接 | 检查 MAX30102 模块接线和供电 |

### 6.3 屏幕工程配置

在 USART HMI 软件中新建工程时注意：
- 设备型号选择对应的 TJC 屏幕型号
- 串口波特率设置为 **115200**
- 画面 ID 默认为 0（首页）

## 7. 参考代码

TJC 驱动已实现，不需要额外编写。关键函数：

```c
// 发送波形数据（channel=0, value=0~255）
TJC_SetWaveform(0, normalized_ppg_value);

// 发送血氧数值（component="n0", value=70~100）
TJC_SetNumber("n0", spo2_value);
```

PPG 波形归一化已内置，原始 16 位 PPG 值会自动映射到 0-255：
```c
uint8_t display_value = TJC_NormalizePPG(raw_ppg_value);
TJC_SetWaveform(0, display_value);
```

## 8. 控件命名规范（重要）

屏幕上的控件名称必须与代码中的命令完全匹配，区分大小写：

| 代码中的名称 | 屏幕控件名 | 用途 |
|-------------|-----------|------|
| `s0` | s0 | PPG 波形显示 |
| `n0` | n0 | SpO2 数值显示 |

> 控件名写错会导致命令无效但不报错，调试时优先检查名称。
