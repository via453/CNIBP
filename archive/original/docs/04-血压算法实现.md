# 第5章 血压算法实现

本章详细阐述本项目中两种无创血压测量算法的具体实现。路线A采用端到端的深度学习方法，仅依赖光电容积脉搏波（PPG）信号重建动脉血压（ABP）波形。路线B基于生理模型，结合心电（ECG）与PPG信号计算脉搏波传导时间（PTT），进而推算血压值。最后对两条路线进行多维度对比分析。

## 5.1 路线A：PPG到ABP深度学习法

路线A的核心思想是借助深度神经网络强大的非线性映射能力，直接从单通道PPG信号中提取特征并重建出连续的ABP波形，随后从波形中提取收缩压（SBP）和舒张压（DBP）。

### 5.1.1 算法原理

传统的特征提取方法依赖人工定义的形态学特征，容易受信号质量和个体差异影响。端到端深度学习范式跳过了繁琐的人工特征工程，让模型在大量数据中自动学习PPG与ABP之间的潜在映射关系。系统输入一段固定长度的PPG信号，模型输出对应长度的ABP波形，实现从光信号到血压波形的直接转换。

### 5.1.2 模型架构

本项目采用双阶段级联架构，包含近似网络和细化网络两个部分，协同完成波形重建。

【插入图片：图5-1 深度学习模型架构图：UNetDS64与MultiResUNet1D双阶段级联示意图】

第一阶段为近似网络（UNetDS64），主要负责粗粒度ABP轮廓的重建。它捕捉信号的低频全局特征，生成血压波形的基础框架。第二阶段为细化网络（MultiResUNet1D），专门用于细节修正。它在第一阶段输出的基础上，进一步还原波形的高频细节，如收缩期尖峰、重搏波切迹等。这种级联设计有效平衡了全局结构与局部细节的重建质量。

### 5.1.3 数据管线

下位机MAX30102传感器以100Hz采样率采集PPG信号。为适配模型输入要求，上位机首先将信号重采样至125Hz。随后，系统采用滑动窗口策略截取1024个数据点作为一个处理批次。截取后的数据经过归一化处理，映射至0到1区间，最后送入模型进行推理。滑动窗口设计保证了数据流的连续性，重叠率的设置则平滑了相邻窗口间的过渡。

### 5.1.4 信号预处理

原始PPG信号常伴有基线漂移和高频噪声。在送入模型前，系统引入了0.5至5Hz的带通滤波。这一频段保留了脉搏波的主要能量，同时有效滤除了呼吸引起的低频基线漂移和环境带来的高频干扰。此外，系统还应用了窗口长度为3的滑动平均滤波，进一步平滑波形，提升模型输入的信噪比。

### 5.1.5 后处理与校准

模型输出的ABP波形同样经过滑动平均处理以消除局部毛刺。血压值的提取基于波形特征：SBP对应波峰值，DBP对应波谷值，平均动脉压（MAP）则通过波形积分平均求得。

由于个体血管顺应性存在差异，模型输出的绝对数值往往存在系统性偏差。系统引入了单点或两点校准机制，通过输入标准血压计测得的真实值，计算并补偿SBP、DBP和MAP的固定偏移量，从而将预测值校准至个体真实水平。

### 5.1.6 版本演进

路线A的上位机算法经历了三个主要版本的迭代，逐步完善了功能与稳定性。

| 版本 | 核心改进与功能 | 存在问题或局限 |
|------|----------------|---------------|
| **v1 (原始版本)** | 基础Flask与Socket.IO Web仪表盘；PPG波形实时显示；SBP、DBP、MAP数值展示；血压趋势图 | 缺乏信号预处理，预测值跳变大；未经校准，血压值偏高；易受环境噪声影响 |
| **v2 (滤波版本)** | 引入0.5至5Hz带通滤波；增加窗口长度为3的滑动平均；预留CALIBRATION字典接口 | 数值稳定性和抗噪能力提升，但校准仍需手动修改代码，体验较差 |
| **v3 (完整版本)** | 界面交互式校准（自动计算偏移量）；CSV数据导出（记录与波形）；一键重置校准 | 功能完整，满足日常使用需求 |

## 5.2 路线B：PTT到ABP心电与光电信号法

路线B基于明确的生理学模型，通过同步采集ECG和PPG信号，计算脉搏波传导时间（PTT），并使用线性回归模型推算血压。

### 5.2.1 算法原理

脉搏波传导时间（PTT）指心脏射血产生的脉搏波沿动脉血管传播至外周测量点所需的时间。生理学研究表明，血压升高会导致血管壁张力增加、血管顺应性下降，进而使脉搏波传播速度加快，PTT缩短。因此，PTT与血压之间存在显著的负相关关系。在本项目中，PTT定义为ECG的R峰到对应PPG波形脚部的时间差。

【插入图片：图5-3 ECG R峰与PPG脚部对应关系图：同步ECG与PPG波形，标注R峰和脚部位置】

### 5.2.2 ECG R峰检测

准确提取ECG的R峰是计算PTT的前提。系统首先对去噪后的ECG信号进行5至30Hz的带通滤波，突出QRS波群特征。随后采用自适应阈值算法结合峰值检测函数定位R峰。自适应阈值基于信号能量动态更新，能够有效应对基线漂移和信号幅值波动，确保在不同测试条件下均能稳定检出R峰。

### 5.2.3 PPG脚部检测

与寻找波峰相比，PPG波形的脚部（收缩期起点）受波形反射影响较小，定位更稳定。系统采用波谷定位法寻找脚部。通过计算信号的一阶差分并寻找零交叉点，算法能够精确锁定波谷位置。为防止误判，系统还会结合相邻RR间隔的一致性过滤异常波谷。

### 5.2.4 PTT计算

受限于硬件采样率（ECG 250Hz，PPG 100Hz），直接计算时间差的精度有限。系统引入抛物线插值技术实现亚样本精度定位。对R峰和脚部附近的三个采样点进行抛物线拟合，求取极值点坐标，将时间分辨率从4毫秒提升至约1毫秒，显著降低了量化误差对PTT计算的影响。

### 5.2.5 BP线性回归模型

基于提取的PTT，系统采用线性回归模型推算血压：
SBP = α₁ × PTT + β₁
DBP = α₂ × PTT + β₂

其中，α和β为回归系数。这些系数通过校准过程确定。单点校准适用于快速启动，使用一组已知血压值调整截距β。两点校准则需要高低两组血压数据，同时拟合斜率α和截距β，精度更高。

### 5.2.6 异常值过滤

运动伪迹或传感器接触不良会导致PTT计算出现离群值。系统设置了150毫秒至400毫秒的生理合理范围检查，剔除明显不合理的PTT。同时，引入基于中位数绝对偏差（MAD）的滑动窗口算法，动态识别并过滤突变值，防止错误数据干扰血压计算。

### 5.2.7 指数平滑与校准

为进一步提升数值稳定性，系统对连续计算的PTT序列应用指数加权移动平均（EWMA）平滑处理。校准环节是路线B的关键。用户输入真实血压值后，系统根据历史PTT数据反推回归系数。两点校准模式下，系统会提示用户在不同状态（如平静和运动后）进行测量，以获取更准确的个体化线性模型。

## 5.3 双路线对比分析

路线A与路线B代表了两种截然不同的技术哲学。本节从多个维度对两者进行交叉对比，探讨其各自的优势与适用场景。

| 对比维度 | 路线A: PPG到ABP深度学习法 | 路线B: PTT到ABP心电与光电法 |
|:---------|:------------------------|:------------------------|
| **输入信号** | 仅PPG(单传感器) | ECG与PPG(双传感器) |
| **核心算法** | UNetDS64与MultiResUNet1D | PTT线性回归 |
| **算法范式** | 端到端数据驱动 | 生理模型驱动 |
| **计算周期** | 约8秒每次(1024点批推理) | 每心跳约1次(约0.8秒) |
| **实时性** | 中等(受推理延迟限制) | 高(逐跳更新) |
| **精度** | 经初步测试，误差范围约±15mmHg | 经初步测试，误差范围约±10mmHg |
| **可解释性** | 低(黑盒模型) | 高(有明确生理基础) |
| **计算复杂度** | 高(需GPU或TensorFlow运行时) | 低(纯信号处理，CPU即可) |
| **模型体积** | 约255MB(两个.h5文件) | 约4个浮点参数 |
| **校准方式** | 偏移补偿(单参数) | 单点或两点校准(调整回归系数) |
| **校准参数数量** | 3个偏移量(SBP、DBP、MAP) | 4个回归系数(2斜率与2截距) |
| **下位机传感器** | MAX30102(PPG) | MAX30102(PPG)与ADS1292R(ECG) |
| **适用场景** | 极简传感器配置，日常趋势监测 | 高精度需求，健康评估 |
| **抗运动伪迹能力** | 弱(端到端模型对输入分布敏感) | 中(可通过PTT异常过滤缓解) |

**原理与范式对比**
路线A是典型的数据驱动黑盒模型，依赖海量数据隐式学习特征。路线B则是白盒模型，建立在明确的血流动力学先验知识之上。前者开发周期短，后者可解释性强。

**精度与实时性对比**
经初步测试，路线A的误差范围约±15mmHg，而路线B的误差范围约±10mmHg。路线B精度更高的原因在于融合了ECG作为绝对时间参考，信息维度更丰富。在实时性方面，路线B能够实现逐心跳更新（约0.8秒每次），而路线A受限于1024点窗口和深度学习推理延迟，更新周期约为8秒。

**复杂度与适用场景**
路线A仅需单一PPG传感器，硬件极简，适合集成于智能戒指或基础手环中进行日常趋势监测。但其计算复杂度高，通常需要上位机或云端算力支持。路线B需要双传感器配合，操作稍显繁琐，但算法轻量，普通单片机即可胜任，适合对精度要求较高的健康评估场景。

**互补性讨论**
两条路线并非竞争替代关系，而是高度互补。在实际应用中，路线B可作为高精度基准，在用户静止时提供可靠测量。路线A则发挥单传感器优势，在用户日常活动中提供连续趋势跟踪。当两者数据出现较大分歧时，系统可提示用户重新校准或检查佩戴状态，从而构建更稳健的无创血压监测体系。
