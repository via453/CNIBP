# 第4章 心电信号去噪研究

在基于脉搏波传导时间（PTT）的无创血压测量路线中，心电（ECG）信号的质量直接决定了R峰定位的精度，进而影响血压计算的准确性。本项目下位机采用了干电极设计，虽然提升了穿戴便捷性，但也引入了更为复杂的噪声干扰。为此，本章对33种心电去噪方法进行了系统性对比与评估，并设计了一套实时批处理自动选优系统。

## 4.1 干电极心电的噪声挑战

与临床常用的湿电极（如Ag/AgCl贴片）相比，干电极无需导电膏，直接与皮肤接触。这种接触方式导致电极-皮肤阻抗显著增加且极不稳定，使得采集到的ECG信号极易受到外界干扰。

【插入图片：图4-1 原始ECG信号与噪声分析 ： 时域/频域联合展示】

在本项目中，干电极ECG信号面临的主要噪声来源包括：
1. **工频干扰及其谐波**：由于环境电磁场耦合，信号中混入了强烈的50Hz工频噪声，以及100Hz、150Hz等高次谐波。
2. **基线漂移（<1Hz）**：主要由呼吸运动和电极接触不良引起，表现为信号整体基准线的缓慢起伏。
3. **肌电噪声（EMG，>100Hz）**：肌肉收缩产生的宽带高频电信号，容易淹没ECG的高频细节。
4. **运动伪迹**：佩戴者手臂晃动导致接触阻抗突变，产生大幅度的低频干扰。

这些噪声如果未经有效处理，会导致R峰检测算法产生大量误检或漏检。R峰位置的微小偏移（哪怕只有几毫秒）都会在PTT计算中被放大，最终导致血压预测值出现严重偏差。因此，寻找一种高效、低延迟且保真度高的去噪算法是路线B成功的关键。

## 4.2 33种去噪方法系统性对比

为了找到最适合本硬件平台的去噪方案，我们构建了一个包含8维无参考评价指标的评估体系（涵盖峰值信噪比PeakSNR、RR互相关、平滑度、带内功率比等），对7大类共33种去噪方法进行了系统性横向对比。

### 4.2.1 七大类方法总结

我们避免了对单一方法的冗长分析，而是将这33种方法归纳为7个大类，各类的核心特点总结如下：

* **A-集成方法（1种）**：采用自适应堆叠融合策略，综合表现最优，但计算开销极大。
* **B-经典滤波（7种）**：以Notch 50/100/150Hz+BP为代表，是表现最好的传统子类（PeakSNR +9.6dB），计算极快。
* **C-子带小波（6种）**：以Wavelet UDWT为代表，在时频局部化处理上具有天然优势，能较好保留波形特征。
* **D-频域法（5种）**：以FFT Gate 0.5-40Hz为代表，通过频域硬截断实现去噪，是本次评测的**全局冠军**（PeakSNR +11.8dB）。
* **E-自适应滤波（6种）**：以NLMS算法为代表，对非平稳噪声的自适应跟踪能力最强，但收敛需要时间。
* **F-机器学习（5种）**：以RNN+Kalman为代表，展现了数据驱动型去噪的潜力，但受限于模型泛化能力。
* **G-SVD类（3种）**：以Hankel+SVD+阈值为代表，通过子空间分解分离信号与噪声，数学解释性强。

**冠军方法突出说明：FFT Gate (0.5-40Hz)**
在所有测试方法中，频域门限法（FFT Gate）以+11.8dB的峰值信噪比提升脱颖而出，位列第一。该方法的核心思路非常直接：将时域信号转换到频域后，强制将0.5Hz以下（基线漂移）和40Hz以上（工频及高频肌电）的频谱系数置零，然后再逆变换回时域。由于干电极引入的50Hz及其谐波能量极大，传统的IIR/FIR带通滤波器在过渡带往往会残留部分噪声，或者引入非线性相位失真。而FFT Gate在频域实现了理想的"砖墙式"滤波，不仅彻底抹除了带外噪声，还完美保持了带内信号的相位线性，使得R峰的形态和时间位置得到了最大程度的保留，为后续的PTT计算提供了极高质量的输入。

## 4.3 实时批处理自动选优系统

虽然FFT Gate在全局统计上表现最优，但在实际穿戴场景中，噪声的分布是动态变化的。例如，在剧烈运动时，自适应滤波可能比频域法更有效。为了应对这种非平稳噪声，我们设计了一套实时批处理自动选优系统。

【插入图片：图4-4 实时批处理系统架构图】

该系统运行在上位机端，采用流式处理架构。其核心工作流如下：
1. **环形缓冲**：系统维护一个长度为10秒的环形缓冲区，持续接收下位机传来的原始ECG数据。
2. **分块处理**：数据以约62个采样点为一个数据块（Block）进行流式更新，系统刷新率保持在4Hz左右，既保证了视觉上的实时性，又积累了足够的计算窗口。
3. **并行评估**：在后台，系统同时运行8种候选去噪方法（从上述Top 15中精选的不同类别代表）。
4. **动态选优**：针对每个处理窗口，系统实时计算各方法的8维评价指标，通过复合评分函数得出当前窗口下的最优方法，并将该方法的输出作为最终的去噪信号展示并传递给下游算法。

这种"以算力换质量"的策略，虽然引入了约300ms的批处理延迟，但极大地提升了系统在复杂干扰环境下的鲁棒性，确保了血压测量的稳定输出。
