# 第7章 实验结果与分析

本章主要对系统各模块的实际运行效果进行测试与评估。测试内容涵盖心电信号去噪算法的性能对比、路线A与路线B的血压测量精度验证，以及双路线的综合对比分析。

## 7.1 ECG去噪效果

在心电（ECG）信号去噪研究中，我们对33种算法进行了系统性测试。根据无参考评价指标体系的综合评分，排名前五的方法在峰值信噪比（PeakSNR）上均取得了显著提升。具体数据可参考`核心数据表.md`中的33种去噪方法排名表。

排名前五的方法分别是：
1. FFT Gate (0.5-40Hz)：PeakSNR提升11.8dB
2. FFT Notch (50/100/150Hz)：PeakSNR提升9.6dB
3. Notch50+100+150 + BP：PeakSNR提升9.6dB
4. Bandpass 1-30Hz：PeakSNR提升9.3dB
5. Wiener (5)：PeakSNR提升8.0dB

其中，频域法中的FFT Gate (0.5-40Hz) 表现最为突出，夺得全局最优效果。该方法通过在频域直接截断0.5Hz以下和40Hz以上的频率成分，不仅彻底消除了基线漂移和高频肌电噪声，还完美保留了QRS波群的形态特征。

【插入图片：图7-1 去噪前后对比图】

从图7-1的时域波形对比可以看出，原始信号中严重的50Hz工频干扰和基线漂移被有效滤除。去噪后的绿色波形平滑且特征明显，R峰清晰可见，为后续的PTT计算提供了高质量的数据基础。结合8维指标雷达图分析，FFT Gate在PeakSNR、平滑度以及带内功率比等维度均达到最优平衡。

## 7.2 路线A实验结果

路线A采用端到端深度学习模型，直接从单通道PPG（光电容积脉搏波）信号重建ABP波形。在实际测试中，我们记录了系统从v1到v3版本的演进效果。

【插入图片：图7-2 路线A版本演进效果对比】

在v1原始版本中，由于缺乏信号预处理，模型输出的血压预测值跳变较大，且未经校准的数值整体偏高。引入0.5-5Hz带通滤波和滑动平均后，v2版本的数值稳定性和抗噪能力得到明显提升。最终的v3版本加入了界面交互式校准功能，通过输入真实血压值自动计算偏移量，使得测量结果更加贴近真实水平。

经初步测试，路线A的误差范围约±15mmHg。产生±15mmHg误差的主要原因在于：单通道PPG信号包含的生理信息量有限，缺乏心电信号作为时间参考。此外，端到端模型对输入数据的分布较为敏感，训练数据集与实际测试人群之间存在的个体差异也会对泛化精度造成一定影响。

## 7.3 路线B实验结果

路线B基于ECG和PPG双传感器提取脉搏波传导时间（PTT），并通过线性回归模型推算血压。

【插入图片：图7-3 PTT-SBP线性关系验证】

图7-3展示了实测PTT与收缩压（SBP）的散点分布及拟合直线。结果表明，在一定生理范围内，PTT与血压呈现出明显的负相关线性关系，验证了该路线的生理学基础。

在校准环节，单点校准能够快速计算出截距偏移，适合快速启动测量。而两点校准通过两组不同状态下的血压数据重新拟合斜率和截距，进一步提升了测量精度。经初步测试，路线B的误差范围约±10mmHg。相比路线A，路线B的精度优势主要来源于融合了ECG信号。ECG的R峰提供了极其精确的心室收缩时间起点，使得PTT的计算更加可靠，从而降低了血压推算的误差。

## 7.4 综合对比

为了更直观地评估两条技术路线的特点，我们从多个维度进行了交叉对比。详细数据参考`核心数据表.md`中的双路线对比表。

| 对比维度 | 路线A: PPG→ABP深度学习法 | 路线B: PTT→ABP心电+光电信号法 |
|:---|:---|:---|
| 精度 | ±15mmHg | ±10mmHg |
| 实时性 | 约8秒/次 | 约0.8秒/次 |
| 便捷性 | 单传感器 | 双传感器 |
| 复杂度 | 需GPU推理 | CPU即可 |
| 适用场景 | 日常趋势监测 | 健康评估 |

综合来看，路线A和路线B并非替代关系，而是互补关系。路线A仅需单传感器，佩戴极其便捷，非常适合日常的血压趋势监测。虽然精度略逊，但足以反映血压的整体变化走向。路线B则需要双传感器配合，操作稍显复杂，但凭借明确的生理模型和更高的测量精度，更适合对数据准确度要求较高的健康评估场景。在实际应用中，两者可以相互参考，在数据异常时进行交叉验证。

# 第8章 总结与展望

## 8.1 项目总结

本项目旨在设计并实现一套便携式多参数无创血压测量手环系统。在整个开发周期中，我们完成了双路线系统架构设计、下位机硬件搭建、心电信号去噪算法研究、血压推算算法实现以及上位机软件开发等核心任务。

最终，我们成功构建了一套完整的血压监测原型系统。该系统最大的特色在于采用了双路线并行的设计理念。路线A探索了前沿的深度学习端到端重建技术，路线B则扎根于经典的生理模型与信号处理方法。两条路线共享同一个底层硬件平台，在功能上形成了完美的互补，既覆盖了日常便捷监测的需求，又兼顾了高精度健康评估的场景。

## 8.2 经验与反思

在项目推进过程中，我们积累了以下三条关键技术经验：

第一，加窗FFT对工频干扰具有出色的抑制效果。在第4章的去噪研究中，FFT Gate方法脱颖而出。这证明在处理周期性极强的50Hz干扰时，直接在频域进行精准截断比传统的时域滤波更加高效彻底。

第二，硬件入口质量决定了整体信号质量的上限。在传感器选型时，我们对比了多种方案，最终确定了MAX30102和ADS1292R的组合。高质量的24位ADC和专用的前端芯片为后续的算法处理提供了极大的便利。如果前端信号底噪过大，再优秀的软件算法也难以挽救。

第三，在工程实践中，适当牺牲时间换取信号优化是完全可行的策略。在实时批处理系统的设计中，我们引入了约300ms的计算延迟。这点延迟在人体生理监测中几乎无法察觉，但却为复杂的去噪算法争取了宝贵的计算窗口，大幅提升了最终输出波形的质量。

## 8.3 不足与改进方向

尽管系统已经具备了完整的功能，但仍存在一些局限性。首先，目前的双路线尚未完全集成到一个统一的便携式硬件外壳中，仍处于原型验证阶段。其次，路线A的深度学习模型在面对个体差异时，泛化能力仍有待提升。最后，路线B的PTT线性模型忽略了血管弹性的非线性特征，在血压极高或极低时可能触及精度边界。

针对上述不足，未来的工作将集中在以下几个方向。首先是开发手机端APP并引入蓝牙无线通信，彻底摆脱USB线缆和PC上位机的束缚，大幅提升系统的便携性。其次，我们计划探索路线C，即构建ECG与PPG多特征融合的残差学习模型（V-Net），以期突破现有线性模型的精度瓶颈。最后，收集更大规模、更多样化的临床数据集对模型进行验证与优化，将是推动该系统走向实际应用的关键一步。
