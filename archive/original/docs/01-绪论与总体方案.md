# 第1章 绪论

## 1.1 无袖带血压测量的背景与意义

心血管疾病是全球范围内的主要健康威胁。高血压作为核心危险因素，其早期发现和长期控制对预防心梗和中风至关重要。临床研究表明，单次诊室血压测量往往无法全面反映患者真实的血压波动。隐匿性高血压、白大衣高血压以及夜间血压异常等现象，都需要连续的血压监测才能被有效捕捉。

传统的血压监测手段主要依赖袖带式血压计。这类设备在临床上被广泛认可，但测量过程需要对上臂或手腕充气加压。这不仅会给使用者带来不适，还无法实现真正的无感连续监测。特别是在夜间睡眠期间，充气过程极易打断患者睡眠，影响测量结果的真实性。

随着可穿戴设备和生物传感技术的发展，无袖带血压测量技术逐渐成为研究热点。目前主流的无袖带测量方案包括脉搏波传导时间(PTT)法、超声法以及单纯的光电容积脉搏波(PPG)法。这些技术通过采集人体的生理信号，结合信号处理和机器学习算法，能够间接推算出收缩压(SBP)和舒张压(DBP)。无袖带技术的兴起，为实现日常、连续、无感的血压监测提供了可能。

## 1.2 传统血压测量的局限性

传统示波法和柯氏音法血压计在原理上存在固有的局限性。它们依赖气泵充气阻断动脉血流，然后通过分析放气过程中的压力震荡波或血管音来确定血压值。这种物理阻断机制决定了设备体积难以进一步缩小，且功耗较高。

以市面上较为先进的欧姆龙HeartGuide腕式血压计为例。尽管它将气泵和袖带微型化并集成到手表形态中，但依然无法摆脱充气测量的本质。使用者在测量时仍需保持特定姿势，充气带来的压迫感依然存在。更重要的是，这类设备每次测量都需要消耗较多电量，两次测量之间必须有足够的间隔时间，无法做到真正意义上的逐心跳实时连续监测。

## 1.3 本项目目标与内容概述

本项目旨在设计并实现一套便携式多参数无创血压测量手环系统。系统涵盖了从下位机硬件信号采集、上位机信号处理到最终血压算法推算与结果显示的完整链路。

为了兼顾不同应用场景的需求，本项目创新性地采用了双技术路线并行的设计方案。
第一是路线A，即PPG到ABP深度学习法。该路线仅依赖单一的PPG传感器，通过端到端的深度学习模型直接重建动脉血压(ABP)波形。
第二是路线B，即PTT到ABP心电加光电信号法。该路线结合心电(ECG)和光电(PPG)双传感器，提取脉搏波传导时间(PTT)，基于生理模型推算血压。

这两条路线共享同一套下位机硬件平台，通过不同的传感器配置和上位机算法，实现了便捷性与高精度的优势互补。

# 第2章 系统总体方案设计

## 2.1 系统总体架构

本系统采用典型的上下位机架构。下位机负责生理信号的实时采集与初步处理，上位机负责复杂算法的运行与数据可视化。

下位机以STM32F103C8T6微控制器为核心，连接MAX30102光电传感器和ADS1292R心电模拟前端。采集到的原始生理数据通过CH340G芯片转换为USB串口信号，实时传输至上位机。上位机接收到数据流后，根据选择的技术路线，运行相应的信号处理管线和血压推算算法，最终在图形界面上展示实时波形和血压数值。

## 2.2 双技术路线设计理念

本项目的核心亮点在于双技术路线并行的设计。在实际应用中，血压监测面临着多样化的需求。日常佩戴更看重设备的轻便和无感，而健康评估则对数据的绝对精度有更高要求。单一的技术方案往往难以兼顾。

因此，我们设计了路线A和路线B。这两条路线并非相互竞争，而是互补验证。它们共享相同的STM32下位机主板，仅在传感器配置和上位机算法上有所区分。这种设计既保证了硬件平台的通用性，又极大地扩展了系统的适用范围。

### 2.2.1 路线A：PPG到ABP深度学习法

路线A追求极致的便捷性。它仅需采集指尖或腕部的PPG信号，无需用户佩戴心电电极。算法层面，路线A摒弃了繁琐的人工特征提取，采用端到端的深度学习范式。模型直接学习从PPG波形到连续动脉血压(ABP)波形的映射关系，进而提取出收缩压和舒张压。

这种方法的优势在于硬件配置极简，非常适合日常的血压趋势监测。但其不足之处在于，由于缺乏心电信号作为时间参考，当用户出现心律不齐或信号受到严重运动干扰时，模型的预测误差会相应增大。

### 2.2.2 路线B：PTT到ABP心电加光电信号法

路线B侧重于测量的准确性和生理可解释性。它需要同时采集ECG和PPG信号。通过精确定位ECG的R峰和PPG波形的脚部，算法可以计算出脉搏波传导时间(PTT)。根据血液动力学原理，PTT与血压之间存在明确的负相关关系。基于这一生理先验，系统建立PTT与血压的线性回归模型，从而推算出具体的血压值。

路线B的优势在于精度更高，经初步测试误差范围可控制在±10mmHg以内。同时算法运行效率高，能够实现逐心跳的实时更新。其局限性在于需要双传感器配合，用户在测量时需要双手接触电极，操作相对复杂。

## 2.3 双路线对比总览

为了更直观地展示两条技术路线的差异与特点，我们从输入信号、核心算法、精度、实时性等多个维度进行了全面对比。

| 对比维度 | 路线A: PPG到ABP深度学习法 | 路线B: PTT到ABP心电加光电法 |
| :--- | :--- | :--- |
| **输入信号** | 仅PPG(单传感器) | ECG + PPG(双传感器) |
| **核心算法** | UNetDS64 + MultiResUNet1D | PTT线性回归 |
| **算法范式** | 端到端数据驱动 | 生理模型驱动 |
| **计算周期** | 约8秒每次(1024点批推理) | 每心跳约1次(约0.8秒) |
| **实时性** | 中等(受推理延迟限制) | 高(逐跳更新) |
| **精度** | 误差范围约±15mmHg | 误差范围约±10mmHg |
| **可解释性** | 低(黑盒模型) | 高(有明确生理基础) |
| **计算复杂度** | 高(需GPU或TensorFlow运行时) | 低(纯信号处理，CPU即可) |
| **模型体积** | 约255MB(两个.h5文件) | 约4个浮点参数 |
| **校准方式** | 偏移补偿(单参数) | 单点或两点校准(调整回归系数) |
| **校准参数数量** | 3个偏移量(SBP/DBP/MAP) | 4个回归系数(2斜率+2截距) |
| **下位机传感器** | MAX30102(PPG) | MAX30102(PPG) + ADS1292R(ECG) |
| **适用场景** | 极简传感器配置，日常趋势监测 | 高精度需求，健康评估 |
| **抗运动伪迹能力** | 弱(端到端模型对输入分布敏感) | 中(可通过PTT异常过滤缓解) |

## 2.4 技术指标与设计约束

为确保系统能够稳定、准确地获取生理信号并完成数据传输，我们在设计之初设定了严格的技术指标与物理约束。

下位机主控采用STM32F103C8T6，运行频率72MHz，提供充足的算力用于传感器驱动和数据打包。在信号采集方面，PPG信号由MAX30102负责，采样率设定为100Hz，采用16位ADC以保证波形细节。ECG信号由ADS1292R采集，采样率设定为250Hz，其24位高精度ADC能够有效捕捉微弱的心电特征。

系统整体尺寸被严格控制在50mm乘35mm以内，以满足手环形态的便携性要求。电源管理采用IP5310芯片，实现锂电池的升压与充电一体化。数据通信方面，采用CH340G芯片实现USB转串口，波特率配置为115200bps，确保双通道高频采样数据能够无延迟地传输至上位机。

在测量精度目标上，路线A的误差范围目标为±15mmHg，路线B的误差范围目标为±10mmHg。这些指标共同构成了本系统的设计基石。
