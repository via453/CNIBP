## 3. 双路线对比表
*数据来源：`章节5_血压算法实现.md`*

| 对比维度 | 路线A: PPG→ABP深度学习法 | 路线B: PTT→ABP心电+光电法 |
|:---------|:------------------------|:------------------------|
| **输入信号** | 仅PPG(单传感器) | ECG + PPG(双传感器) |
| **核心算法** | UNetDS64 + MultiResUNet1D | PTT线性回归 |
| **算法范式** | 端到端数据驱动 | 生理模型驱动 |
| **计算周期** | ~8秒/次(1024点批推理) | 每心跳约1次(~0.8秒) |
| **实时性** | 中等(受推理延迟限制) | 高(逐跳更新) |
| **精度** | 误差范围约±15mmHg | 误差范围约±10mmHg |
| **可解释性** | 低(黑盒模型) | 高(有明确生理基础) |
| **计算复杂度** | 高(需GPU/TensorFlow运行时) | 低(纯信号处理,CPU即可) |
| **模型体积** | 约255MB(两个.h5文件) | 约4个浮点参数 |
| **校准方式** | 偏移补偿(单参数) | 单点/两点校准(调整回归系数) |
| **校准参数数量** | 3个偏移量(SBP/DBP/MAP) | 4个回归系数(2斜率+2截距) |
| **下位机传感器** | MAX30102(PPG) | MAX30102(PPG)+ADS1292R(ECG) |
| **适用场景** | 极简传感器配置,日常趋势监测 | 高精度需求,健康评估 |
| **抗运动伪迹能力** | 弱(端到端模型对输入分布敏感) | 中(可通过PTT异常过滤缓解) |

## 4. 版本演进表
*数据来源：`章节5_血压算法实现.md`*

| 版本 | 核心改进与功能 | 存在问题/局限 |
|------|----------------|---------------|
| **v1 (原始版本)** | 基础Flask+Socket.IO Web仪表盘；PPG波形实时显示；SBP/DBP/MAP数值展示；血压趋势图 | 缺乏信号预处理，预测值跳变大；未经校准，血压值偏高；易受环境噪声影响 |
| **v2 (滤波版本)** | 引入0.5-5Hz带通滤波；增加窗口长度为3的滑动平均；预留CALIBRATION字典接口 | 数值稳定性和抗噪能力提升，但校准仍需手动修改代码，体验较差 |
| **v3 (完整版本)** | 界面交互式校准（自动计算偏移量）；CSV数据导出（记录与波形）；一键重置校准 | 功能完整，满足日常使用需求 |
